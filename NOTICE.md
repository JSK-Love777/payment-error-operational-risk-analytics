# Notice

## Dataset attribution

This portfolio uses the public **Financial Transactions Dataset: Analytics** published by ComputingVictor on Kaggle:

https://www.kaggle.com/datasets/computingvictor/transactions-fraud-datasets

The underlying data is third-party content and is not redistributed in this repository. Users reproducing the analysis should review the current dataset page and its license/terms before downloading or reusing the source files.

## Portfolio scope

This repository presents descriptive and diagnostic payment-error analysis. It is not a production fraud-detection model and does not establish causality.
